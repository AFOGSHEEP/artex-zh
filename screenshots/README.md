# 截图说明 (Screenshots)

中文 · [English below](#english)

本文件夹存放两套不同的界面截图。为避免混淆，先说明各自是什么。

- **根目录的 `*.png`：ARTEX 中文版（上游原版）的实际 UI 截图。** 这也是本仓库交付
  的成果——主文档 [`../README.md`](../README.md) 使用的就是这些图片。中文版界面
  请直接查看根目录。
- **`ko/`：上游韩文版（jiwoochris/artex-ko）的 UI 截图。** 为便于与韩文版仓库
  1:1 对照而**原样保留**，保留的韩文说明 [`../README.ko.md`](../README.ko.md)
  引用这些图片。中文与英文文档不使用它们。
- **`wx.png`：上游原作者的微信公众号推广图。** 一并保留以便历史资料完整，与
  中文版功能无关。

简言之：根目录就是中文版界面截图；[`ko/`](ko/) 里是韩文版存档截图。本仓库为何
保留原版对照（本地化透明性·上游对照），与防御·检测的定位一脉相承，背景见根
README。

---

## English

This folder holds two separate sets of captures. To keep them from looking mixed, here
is what each one is.

- **The `*.png` files in the root — real UI of the Chinese edition of ARTEX.** This is
  what this repository delivers; the main doc [`../README.md`](../README.md) uses these
  images.
- **`ko/` — upstream Korean edition (jiwoochris/artex-ko) UI captures.** They are
  **preserved as-is** so the repository can be diffed against the Korean fork 1:1, and
  the preserved Korean README [`../README.ko.md`](../README.ko.md) references them. The
  Chinese and English docs do not use them.
- **`wx.png` — the original upstream author's WeChat channel promo image.** Kept for
  archival completeness; unrelated to the Chinese edition's functionality.

In short: the root holds the Chinese edition's screens; the Korean edition's archived
screens live in [`ko/`](ko/). See the root README for why this fork keeps the originals
alongside (localization transparency and upstream comparison).
